03Implementado · mejora continua

Automatización de Gestión de Líneas Corporativas

Transformación de un proceso basado en correos dispersos en un flujo centralizado, automatizado, trazable y medible para solicitudes de líneas nuevas, reposiciones y bajas.

ResultadoMedición inicial: más del 80 % de los requerimientos fueron procesados el mismo día hábil o durante el siguiente día hábil.
Power AutomateMicrosoft FormsMicrosoft TeamsFlow BotOutlook / M365JSONHTML / CSSSLA
Ver alcance técnico

Microsoft Forms funciona como punto único de registro. Power Automate procesa datos y reglas según el tipo de requerimiento, utiliza JSON para estructurar información dinámica, mantiene registro y trazabilidad, y genera comunicaciones automáticas mediante Outlook / Microsoft 365 con correos HTML/CSS.

La segunda fase integró notificaciones automáticas mediante Flow Bot en Microsoft Teams tanto para TI como para el usuario solicitante. El flujo productivo cubre registro, validación, proveedor, seguimiento y cierre; actualmente continúa evolucionando mediante nuevas automatizaciones y mejoras operativas.
