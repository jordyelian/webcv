# Web CV — Jordy Elian Figueroa Martínez

Versión profesional 2026 del portafolio web para GitHub Pages.

## Estructura

- `index.html` — estructura y contenido principal.
- `assets/css/styles.css` — diseño responsive, animaciones y estilos.
- `assets/js/main.js` — menú móvil, navegación activa, reveals y copia de email.
- `assets/img/jordy-profile.webp` / `.jpg` — fotografía optimizada.
- `assets/img/og-cover.jpg` — preview para LinkedIn, WhatsApp y redes sociales.
- `assets/img/favicon.svg` — favicon.
- `assets/docs/cv-jordy-figueroa.pdf` — CV actualizado.

## Publicación en GitHub Pages

1. Reemplaza el contenido del repositorio `webcv` por estos archivos.
2. Haz commit y push a la rama publicada por GitHub Pages.
3. La URL se mantiene en `https://jordyelian.github.io/webcv/`.

## Recomendación después de publicar

LinkedIn y WhatsApp pueden conservar una vista previa anterior en caché. La nueva imagen Open Graph es `assets/img/og-cover.jpg`.
